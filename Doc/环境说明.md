# Rtos_Learn 环境说明

本文档整理当前工程所需的开发环境、工具链和常用操作。

## 1. 工程概况

- 工程类型：STM32CubeMX 生成的 CMake 工程
- 芯片：STM32F405RGTx
- 构建系统：CMake + Ninja
- 主要调试/烧录：J-Link

  - `arm-none-eabi-objcopy`
  - `arm-none-eabi-size`

### 2.2 IDE / 编辑器

- Visual Studio Code
- CMake Tools
- Cortex-Debug
- C/C++ 扩展

### 2.3 调试器 / 烧录器

- SEGGER J-Link

## 4. 工程配置

### 4.1 CMake 预设

工程使用 `CMakePresets.json`，主要预设：

- `Debug`
- `Release`

构建目录：

- `build/Debug`
- `build/Release`

### 4.2 Toolchain

工具链文件：

- `cmake/gcc-arm-none-eabi.cmake`

主要参数：

- Cortex-M4
- Hard FPU
- `-O0 -g3` 用于 Debug
- `-Os -g0` 用于 Release

### 4.3 VS Code 调试

调试配置文件：

- `.vscode/launch.json`

当前调试方式：

- `cortex-debug`
- `servertype = jlink`
- `interface = swd`

## 5. 常用命令

### 5.1 配置

```powershell
cmake --preset Debug
```

### 5.2 编译

```powershell
cmake --build --preset Debug
```

### 5.3 J-Link 烧录

```powershell
& "C:\Program Files\SEGGER\JLink_V798\JLink.exe" -device STM32F405RG -if SWD -speed 4000 -autoconnect 1 -CommanderScript flash.jlink
```

### 5.4 调试

在 VS Code 中选择：

```text
Debug STM32F405 with J-Link
```

然后按 `F5`。

## 6. 新增用户代码

新增自己的源码时，建议放在：

- `User/my_rtos/src`
- `User/my_rtos/Inc`
- `User/Lib/Src`
- `User/Lib/Inc`

在顶层 `CMakeLists.txt` 中加入：

```cmake
target_sources(${CMAKE_PROJECT_NAME} PRIVATE
    User/my_rtos/src/xxx.c
)

target_include_directories(${CMAKE_PROJECT_NAME} PRIVATE
    User/my_rtos/Inc
)
```

注意：`target_include_directories()` 里写的是**目录**，不是 `.h` 文件。
